# librotdea (Backend Spring Boot)
Ejecutar: `./mvnw spring-boot:run` o `mvn spring-boot:run` (puerto 8080)
- Swagger: http://localhost:8080/swagger-ui.html
- H2 console: http://localhost:8080/h2-console (JDBC: jdbc:h2:mem:book, user sa, pass sa)
- API: /api/books (GET, POST), /api/books/{id} (GET, PUT, DELETE), /api/books/search?name=
